# PT FIBERTERRA NETWORK

> **Koneksi Fiber untuk Masa Depan**  
> Solusi konektivitas internet *full fiber optic* berkecepatan tinggi, stabil, dan tanpa batas kuota (Non-FUP) untuk residensial dan bisnis dalam ekosistem **PT Acehlink Media**.

---

## 📌 Sekilas Tentang Proyek

Website corporate resmi **PT FIBERTERRA NETWORK** dirancang dengan pendekatan *Modern Corporate Minimalism*, *Premium Telecommunications Branding*, dan tata letak yang bersih (*clean layout*). Website ini berfungsi sebagai portal informasi korporasi sekaligus sarana interaktif bagi calon pelanggan untuk memeriksa ketersediaan jaringan, mempelajari detail paket internet resmi, serta mengajukan pemasangan baru.

### 🌐 Sinergi Ekosistem AcehLink
FiberTerra beroperasi sebagai lini layanan konektivitas internet berbasis serat optik (*fiber optic*) dalam ekosistem teknologi **PT Acehlink Media** (penyedia solusi teknologi informasi dan infrastruktur jaringan yang berdiri sejak tahun 2010 di Banda Aceh).

---

## ✨ Fitur & Arsitektur Website (Section A – O)

Website dibangun dengan arsitektur satu halaman (*Single Page Architecture*) modular dan semantik, mencakup 15 bagian utama:

- **Section A — Sticky Navbar**: Header tetap (*sticky*) dengan logo resmi PT FIBERTERRA NETWORK sebagai tombol beranda, tautan navigasi mulus (*smooth scrolling*), tombol *Cek Cakupan*, dan tombol *Hubungi Kami*. Didukung menu hamburger yang responsif pada layar ponsel.
- **Section B — Hero Section**: Headline korporat persuasif, subheadline, tombol CTA ganda, lencana ringkas (*Full Fiber Optic*, *Non-FUP Kuota*, *Instalasi Cepat*), serta kartu pratinjau brosur resmi.
- **Section C — Trust & Value Proposition**: 4 pilar keunggulan utama layanan (Teknologi Serat Optik Murni, Paket Transparan Tanpa FUP, Pelayanan Berorientasi Pelanggan, dan Kesiapan Dukungan Teknis).
- **Section D — About Company & Ecosystem**: Profil korporasi, visi dan misi jangka panjang, nilai-nilai perusahaan, pendekatan infrastruktur, serta pernyataan resmi keterhubungan netral dengan ekosistem PT Acehlink Media.
- **Section E — Services**: Katalog layanan spesifik (Internet Residensial / FTTH, Internet Bisnis & UMKM, Konsultasi Jaringan & Managed Wi-Fi).
- **Section F — Internet Plans & Pricing**: Kartu perbandingan paket internet resmi terverifikasi lengkap dengan rincian kecepatan, biaya bulanan, biaya registrasi awal, dan add-on paket televisi kabel interaktif.
- **Section G — Network Coverage Checker**: Alat interaktif pemeriksaan ketersediaan jaringan bertingkat (Provinsi Aceh -> Kota Banda Aceh / Kab. Aceh Besar -> Kecamatan -> Desa/Gampong) dengan simulasi status cakupan dan opsi konfirmasi via WhatsApp.
- **Section H — Subscription Flow**: 4 langkah mudah alur registrasi pelanggan baru (Pilih Paket & Cek Lokasi, Verifikasi Data, Jadwal Instalasi, Aktivasi & Serah Terima).
- **Section I — FAQ (Tanya Jawab)**: Akordeon interaktif yang dikelompokkan berdasarkan kategori (Umum, Teknis, Pembayaran) disertai fitur pencarian instan (*real-time filter*).
- **Section J — Help & Support Channels**: Kanal pusat bantuan resmi (Dukungan Pelanggan, Layanan WhatsApp Cepat, Email Bantuan, dan Info Jam Operasional).
- **Section K — Contact & Lead Generation Form**: Formulir konsultasi berlangganan dengan validasi input interaktif dan integrasi langsung ke pesan WhatsApp customer care.
- **Section L — Proof Points & Network Quality**: Ringkasan jaminan mutu konektivitas (Infrastruktur Fiber Optik Murni, Latensi Rendah, Transparansi Tarif).
- **Section M — Final Call to Action (CTA)**: Banner penutup persuasif yang mengajak pengunjung untuk segera terhubung ke jaringan FiberTerra.
- **Section N — Corporate Footer**: Informasi legal korporat, alamat kantor pusat di Banda Aceh, jam operasional, tautan navigasi, dan hak cipta.
- **Section O — Modals**:
  1. Modal Brosur Resmi (*Pricelist Preview*) dengan tampilan beresolusi tinggi.
  2. Modal Kebijakan Privasi (*Privacy Policy*).
  3. Modal Syarat & Ketentuan Berlangganan (*Terms of Service*).

## 🎨 Design System & Teknologi

### Teknologi yang Digunakan
- **HTML5**: Semantik (*header*, *nav*, *main*, *section*, *article*, *footer*), aksesibilitas ARIA (*roles*, *aria-expanded*, *aria-controls*).
- **CSS3**: CSS Custom Properties (Design Tokens), Flexbox & CSS Grid, Fluid Typography (`clamp()`), transisi halus, mobile-first responsive breakpoints.
- **Vanilla JavaScript (ES6+)**: Zero dependencies, performa tinggi, interaksi DOM cepat (DOM content loaded, intersection observer untuk navbar scroll, cascading select, filter FAQ, form submission WhatsApp, modal state controller).
- **Tipografi**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) via Google Fonts (weights: 400, 500, 600, 700, 800).
- **Ikon**: Inline SVG kustom bergaya Lucide / Feather Icons (tanpa external font icons, bebas render-blocking).

## 🚀 Panduan Menjalankan Proyek Secara Lokal

Website ini merupakan aplikasi web murni (*pure static frontend*) tanpa proses *build* atau dependensi Node.js. Anda dapat langsung membukanya di browser atau menggunakan server lokal:

### Opsi 1: Menggunakan Python
```bash
# Masuk ke folder proyek
cd FIBERTERRA-NETWORK

# Jalankan server lokal (Python 3)
python -m http.server 3000
```
Buka peramban di: `http://localhost:3000`

### Opsi 2: Menggunakan Node.js (`serve` atau `live-server`)
```bash
npx serve .
# atau
npx live-server
```

### Opsi 3: VS Code Live Server
1. Buka folder proyek di Visual Studio Code.
2. Klik kanan pada berkas `index.html`.
3. Pilih **Open with Live Server**.
